# `app/libs`

Native OCR AARs are **no longer used** here.

Inscription recognition uses the Gradle module **`:ppocr-sdk`** (official PaddleOCR
Android ONNX SDK) with Microsoft `onnxruntime-android`, which is 16 KB page-size
aligned for Google Play.

See [`../../ppocr-sdk/README.md`](../../ppocr-sdk/README.md) and the root
[`README.md`](../../README.md).
